# Support

Use:

- **GitHub Discussions** for setup questions, workflow design, and model/benchmark integration ideas;
- **GitHub Issues** for reproducible bugs and feature requests;
- **Security → Report a vulnerability** for security issues.

Before opening an issue, run:

```bash
python skills/embodied-eval-automation/scripts/validate_repository.py .
python -m unittest discover -s tests -v
```

Remove tokens, passwords, private hosts, personal paths, institutional names, and proprietary episode content from all reports.

This community project does not provide an SLA, cloud credits, model licenses, benchmark access, or guaranteed compatibility with every model and simulator.
